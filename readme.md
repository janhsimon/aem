# What is *Alpha*?

*Alpha* is a game development toolkit. Not an engine, but a collection of file formats, tools and editors to help you make your dream game in less time.


# What is in the *Alpha* toolkit?

*Alpha* consists of two main components:
- AEM: A file format for 3D models
- AMP: A file format for 3D maps

Here is an overview of what folders the repository contains:
- `aem-compiler`: A command-line tool that converts GLB and GLTF into AEM files
- `aem-studio`: An application that loads and renders AEM files and can be used to inspect and debug models
- `alpha-zero`: A simple first-person shooter game that demonstrates what you can do with the *Alpha* toolkit
- `amp-machine`: A Hammer-style world editor to create your own AMP files with
- `external`: Third-party binaries used across the repository
- `libaem`: A minimal and dependency-free C library that can load and animate AEM files efficiently
- `util`: Custom utility functionality used across the repository
- `aem.md`: The AEM file format specification
